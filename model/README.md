# Promoted model

`model-lock.json` identifies the immutable, quality-gated retrieval model used
by the release pipeline. `model.json` is generated by the training workflow;
do not edit it manually. The application build verifies its SHA-256 checksum
before packaging it for local inference on the OCI instance.

The lock may point to a Hugging Face revision or to the repository fallback;
the build verifies the same checksum in either case.
